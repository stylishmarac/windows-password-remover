## FAQ

**Will it delete my files?**  
No. Only the account password is changed — your data is untouched.

**Does it work with Microsoft accounts?**  
It works for local accounts. Microsoft accounts need to be converted to local first.

## Requirements

- Windows 10 / 11 (64-bit)
- USB drive (4 GB minimum) to create bootable media
- Administrator rights
